# 📚 BookStore - Aplikasi Web Manajemen Toko Buku Online

Proyek aplikasi web manajemen toko buku interaktif berbasis HTML5 dan CSS3 murni. Aplikasi ini mencakup halaman autentikasi, dashboard utama, manajemen katalog buku, laporan pemesanan, pelacakan pengiriman (tracking), dan riwayat transaksi.

---

## 🚀 Fitur Utama

- **Halaman Autentikasi (`login.html`):** Form login pengguna yang bersih dengan modal bantuan untuk pemulihan kata sandi (lupa password).
- **Dashboard Utama (`dashboard.html`):** Panel navigasi modern dengan tata letak kartu yang responsif untuk mengarahkan pengguna ke seluruh modul sistem.
- **Katalog & Stok Buku (`stok.html`):**
  - Form input penambahan stok buku baru.
  - Tabel daftar katalog buku interaktif lengkap dengan tampilan sampul gambar.
- **Pemesanan Buku / Checkout (`checkout.html`):**
  - Form entri data pemesan, alamat, pilihan buku, serta metode pembayaran.
  - Tabel daftar pesanan masuk dengan opsi aksi manajemen (seperti hapus pesanan).
- **Tracking Pengiriman (`tracking.html`):**
  - Form pencarian status pengiriman berdasarkan Nomor Delivery Order (DO) / Resi.
  - Kartu informasi rincian status perjalanan paket secara visual.
- **History & Transaksi (`transaksi.html`):**
  - Tabel rekapitulasi riwayat transaksi penjualan beserta indikator status pembayaran (_Selesai_ / _Pending_).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik untuk form, tabel, dan navigasi.
- **CSS3:** Penggunaan _Flexbox_, _CSS Grid_, variabel warna modern, dan animasi transisi responsif.
- **SVG Icons:** Vector graphic internal untuk efisiensi performa tanpa library pihak ketiga.

---

## 💻 Cara Menjalankan Proyek

1. **Unduh / Ekstrak** seluruh file proyek ke komputer Anda.
2. Pastikan semua file `.html` berada dalam satu folder root (`tugas_uts_web1`).
3. Buka file **`login.html`** atau **`dashboard.html`** menggunakan browser web (Chrome, Firefox, Edge, atau Safari).
4. Klik tombol/kartu navigasi untuk berpindah antar halaman secara langsung.
